# MoonBit 8 月黑客松项目申报书

申报人：廖柳茵  
项目名称：moonbit-visual-caliper  
项目方向：应用生态 / 工业视觉测量基础库

## 项目概述

`moonbit-visual-caliper` 是一个面向工业测量场景的 MoonBit 原生视觉卡尺库。它围绕工厂视觉检测中的典型流程展开：灰度图采样、测量线剖面生成、边缘转折定位、直线与圆几何拟合、像素到毫米等物理单位换算、公差判定以及报告输出。项目不追求成为大而全的通用图像处理框架，而是沉淀一条清晰、可测试、可复用的尺寸测量 pipeline，让 MoonBit 生态中出现一个垂直但可扩展的工业视觉样例。

## 工程目标与范围

本阶段交付纯 MoonBit 核心库、命令行演示、单元测试、文档和 CI。核心能力包括 `GrayImage` 灰度图容器、双线性采样、Sobel 边缘强度、沿任意线段的 profile caliper、亚像素边缘插值、宽度测量、直线/圆拟合、标准件标定、公差带 PASS/WARN/FAIL 判定和 Markdown 报告生成。后续可以扩展为 Hough 累加器、相机标定模型、JSON/CSV 报告、图像解码适配层和 Web 可视化演示。

## 技术方案

项目采用零 FFI、模块化 MoonBit 实现。公共类型放在根包，便于 `moon info` 生成稳定接口；算法按 `image/profile/geometry/calibration/tolerance/report` 拆分。测试覆盖合成样件的边缘宽度、标定换算、公差判定、报告文本、直线拟合和圆拟合。CI 参考 MoonBit 社区 workflow 模板和已有参赛项目实践，在 Ubuntu、macOS、Windows 上执行格式、检查、测试和接口生成检查。

## 可行性与生态价值

mooncakes.io 已有通用图像处理和图像解码方向项目，但缺少聚焦工业视觉量规的成熟包。本项目范围适中，第一阶段不依赖外部图像格式即可验证核心测量逻辑，同时保留接入生态图像库的空间。它能为 MoonBit 在制造质检、几何算法、可解释工程工具方面提供一个清楚、可运行、可维护的示例。
