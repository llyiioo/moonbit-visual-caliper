# Sources And Originality

This repository is an original MoonBit implementation created for the August MoonBit hackathon.

## Ecosystem Check

Before selecting the scope, mooncakes.io was searched with keywords around image, vision, hough, canny, and caliper. The search showed general-purpose image and graphics projects such as image decoders and image-processing libraries, but no mature industrial visual-caliper package focused on measurement tolerances and reporting.

The project therefore avoids duplicating a general image framework. It focuses on a reusable measurement core that can later integrate with existing image libraries.

## AI Assistance

AI tools were used for planning, code drafting, test drafting, and documentation assistance. The project goal, scope, repository contents, validation, license, and final submission responsibility remain with the repository owner.

No private, closed-source, or commercially restricted source code was copied into this repository.
